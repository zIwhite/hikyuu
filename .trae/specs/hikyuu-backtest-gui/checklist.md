# Hikyuu 策略回测可视化GUI - 验证检查清单

## 基础功能验证
- [ ] 应用能通过 `python app.py` 正常启动，无报错
- [ ] 浏览器能自动打开或手动访问URL能看到界面
- [ ] 界面布局清晰，左侧参数区、右侧结果区分明
- [ ] 界面中文字体显示正常，无乱码

## 股票选择验证
- [ ] 输入正确股票代码（如sh600000）能识别并显示股票名称
- [ ] 输入深市股票（如sz000001）能正常识别
- [ ] 输入不存在的股票代码显示友好错误提示
- [ ] 快捷选择功能正常

## 策略与参数验证
- [ ] 策略下拉框能正常展开，显示"双均线策略"
- [ ] 选择策略后对应参数区域正确显示
- [ ] 滑块拖动时数值同步更新
- [ ] 输入框输入数值时滑块同步更新
- [ ] 参数有合理的范围限制（如均线周期5-200）

## 回测执行验证
- [ ] 点击"开始回测"按钮后执行回测
- [ ] 回测过程中界面不卡死，有进度提示
- [ ] 回测完成后自动跳转到结果展示
- [ ] 使用默认参数回测sh600000能得到有效结果

## 绩效指标验证
- [ ] 显示总收益率，数值与Hikyuu计算一致
- [ ] 显示胜率（赢利交易比例）
- [ ] 显示最大回撤
- [ ] 显示交易次数
- [ ] 显示年化收益率
- [ ] 显示盈亏比
- [ ] 盈利指标用红色/正向显示，亏损用绿色/负向显示

## K线图验证
- [ ] K线图正常显示，蜡烛图形态正确
- [ ] 快线（短期均线）正确叠加
- [ ] 慢线（长期均线）正确叠加
- [ ] 买入点用向上箭头标记，颜色醒目
- [ ] 卖出点用向下箭头标记，颜色醒目
- [ ] 图表有标题和坐标轴标签

## 交易记录验证
- [ ] 表格显示所有交易记录
- [ ] 每条记录包含：日期、方向、价格、数量、金额、盈亏
- [ ] 记录按日期倒序排列（最新在前）
- [ ] 盈利记录用红色标注，亏损用绿色标注
- [ ] 交易数据与绩效指标对应一致

## 资金曲线验证
- [ ] 资金曲线图正常显示
- [ ] 曲线走势与交易记录对应
- [ ] 初始资金线标注清晰
- [ ] 最高点和最低点有标注

## 错误处理验证
- [ ] 未选择股票点击回测有提示
- [ ] 无效参数（如快线>慢线）有错误提示

- [ ] 任何错误都不会导致程序崩溃
