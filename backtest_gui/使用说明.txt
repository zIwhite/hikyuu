===============================
  Hikyuu 策略回测可视化工具
  使用说明
===============================

【快速开始】
1. 双击 start.bat 启动程序
2. 等待浏览器自动打开（约3-5秒）
3. 在左侧设置参数，点击"开始回测"
4. 在右侧查看回测结果

【界面说明】
┌─────────────────────────────────────────┐
│ 左侧：参数设置区                         │
│   · 股票选择：输入股票代码               │
│   · 策略选择：选择回测策略               │
│   · 策略参数：调整各项参数               │
│   · 开始回测按钮：点击运行               │
├─────────────────────────────────────────┤
│ 右侧：结果展示区（四个标签页）           │
│   · 绩效概览：收益率、胜率等指标         │
│   · K线图：走势图和买卖点               │
│   · 交易记录：每笔交易明细               │
│   · 资金曲线：账户净值变化               │
└─────────────────────────────────────────┘

【参数说明】
· 快线周期：短期均线天数（5-100）
· 慢线周期：长期均线天数（10-200）
· 止损比例：亏损到多少就卖出（1%-20%）
· 初始资金：一开始有多少钱
· 买入数量：每次买多少股
· 回测天数：用最近多少天的数据来测

【策略说明】
双均线策略：
  · 快线从下往上穿过慢线 → 买入
  · 快线从上往下穿过慢线 → 卖出
  · 加上止损保护，亏损到止损线也卖出

【常见问题】
Q: 提示"未找到该股票"怎么办？
A: 请先用 HikyuuTDX 工具下载该股票的数据

Q: 股票代码怎么填？
A: 沪市股票以sh开头（如sh600000），
   深市股票以sz开头（如sz000001）

Q: 回测结果可信吗？
A: 回测是基于历史数据，仅供参考，
   不代表未来收益

Q: 怎么退出？
A: 关闭浏览器，然后在命令行窗口按 Ctrl+C

【技术支持】
如遇到问题，请检查：
1. Python 版本是否为 3.10 或 3.11
2. Hikyuu 是否已正确安装
3. 是否下载了股票历史数据
